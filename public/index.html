Capabilities

Everything you need to run untrusted code.

A clean library, a CLI, and a dashboard. No Kubernetes. No daemons to babysit. Just hard isolation that boots faster than a container.

Millisecond boot
Cold-start a fresh sandbox in ~150ms. Fast enough to spin one up per request, per user, or per task.
Docker → VM
Hand any Docker image to create_vm. BandSox builds a rootfs on demand and boots it.
Pause · Snapshot · Restore
Freeze a VM mid-execution, persist its state, and resume later. Perfect for long-running agents.
Web dashboard
Login, manage API keys, browse files, and open in-browser terminal sessions on running VMs.
Python & TypeScript SDKs
First-class Python API plus a Node.js TypeScript SDK. Same primitives across both.
Optional auth
API keys for programmatic access, HMAC-signed sessions for the dashboard. Off by default, one command to enable.
Quickstart

Four lines from pip install to running code in a microVM.

Install with pip, initialize the kernel and CNI artifacts, then create a VM from any Docker image. BandSox handles the rootfs, networking, and the in-guest agent.

uv pip install bandsox
~/sandbox.py
from bandsox.core import BandSox bs = BandSox() vm = bs.create_vm("python:3-alpine", enable_networking=False) result = vm.exec_python_capture("print('Hello from VM!')") print(result['stdout']) # Hello from VM! vm.stop()
import { BandSox } from "bandsox"; const bs = new BandSox({ baseUrl: "http://your-server:8000" }); const vm = await bs.createVm({ image: "python:3-alpine" }); const result = await vm.execPython({ code: "print('Hello from VM!')" }); console.log(result.stdout); // Hello from VM! await vm.stop();

A CLI that mirrors the API.

Every Python call has a CLI counterpart — create, pause, snapshot, restore, terminal, serve. Manage auth, keys, and the dashboard from the same binary.

Architecture

Four small modules. No magic.

BandSox is intentionally compact. Each module owns one job and stays out of the others' way.

bandsox.core
Manages VMs, snapshots, and resource allocation. The top-level entrypoint.
bandsox.vm
Owns the VM lifecycle — config, networking, the guest bridge, and I/O.
bandsox/agent
Static Go binary baked into every VM image. Runs commands and transfers files over serial and vsock.
bandsox.server
FastAPI backend for the dashboard and REST API, with optional auth baked in.
bandsox.auth
Hashed API keys, HMAC-signed sessions, login rate-limiting. Stateless. Off until you turn it on.
